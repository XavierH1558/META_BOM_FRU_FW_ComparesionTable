# dev-tools/

Ad-hoc scripts used during development for manual debugging (e.g. checking Google
Drive shared-folder listings, testing match logic against sample data). They are
not part of the app and are not run automatically by anything — feel free to
delete any of them once you're confident you no longer need them for reference.

Moved here from `scratch/` on 2026-08-10 to make it clear (at a glance) that
these aren't part of the real test suite (`test_v2_features.py` in the project
root is).
